   Read docs_dir / 'exchange_schema.csv'. For each file in {profile_PCNR.csv, name_map.csv, source_inventory.csv}:
   - Get expected required columns from schema (where required=='Y').
   - Read actual headers from exchange_dir / file using csv.DictReader (first row only).
   - Collect any required column absent from actual headers.
   Returns list of error strings. Empty list = valid.

   a. argparse: --exchange (default str(EXCHANGE_PATH)), --out (default str(OUT_PATH)),

   g. On success: print(f"written: {out / 'pdd_v1_0.xlsx'}"). Return 0.
   h. On ValueError from verify: logging.error + return 1.

6. if __name__ == "__main__": sys.exit(main())
