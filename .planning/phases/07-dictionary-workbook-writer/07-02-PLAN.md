LOCKED TRANSFORM ORDER (do not deviate):
  1. Load raw profile_PCNR.csv into DataFrame.
  2. apply_age_topcode(df, age_vars): modifies LEVEL rows and STAT value column.
     After aggregating '90+' LEVEL rows: recompute pct_total = n_merged/total_rows*100,
     pct_nonmiss = n_merged/n_nonmiss_for_var*100, and recompute small_cell_flag
     ('Y' if 1<=n_merged<=10, else 'N').
  3. apply_numtext_mask(df): for NUM_TEXT rows where stat='LEVEL' and 1<=float(n)<=10,
     replace level text with 'other text entry'. Runs BEFORE suppression.
  4. apply_suppression(df, config): primary then complementary suppression.
  5. Build dist_row from final df (post all transforms). Enumerate rows to get row numbers.
  6. Build sheets from transformed df only.

Column semantics (profile_PCNR.csv):
  - n column: counts (LEVEL/OTHER/MISSING/N/N_MISSING/N_UNPARSED/N_DISTINCT rows). Cast to int for display.
  - value column: statistics (MEAN/SD/MEDIAN/Q1/Q3/MIN/MAX/RANGE_MIN/RANGE_MAX rows). Keep as float.
  - Age topcode: check value column for STAT rows; check level column for LEVEL rows.

n_nonmiss derivation per var_class (computed after transforms):
  LOW_CARD / HIGH_CARD: total_rows - n where stat='MISSING' for that variable.
  CONT_NUM / DATE / NUM_TEXT / SUPPRESSED: n where stat='N' for that variable.
  all_missing=Y when n_nonmiss==0.

MISSING row suppression leak prevention:
  If a variable's MISSING row is suppressed (n becomes '<11'), then in VARIABLES sheet:
  - n_nonmiss column: show '<11 missing' (not a computed integer).
  - pct_missing column: show blank.

all_missing variables (n_nonmiss==0):
  summary = "No values (100% missing)". n_nonmiss=0, pct_missing=100.0, all_missing='Y'.

NUM_TEXT unparsed LEVEL masking:
  apply_numtext_mask(df): before suppression, for rows where var_class='NUM_TEXT' and stat='LEVEL'
  and pd.to_numeric(df['n'], errors='coerce') is between 1 and 10 inclusive,
  replace df['level'] with 'other text entry'. Return modified df.

Complementary suppression:
  After primary suppression (mode='suppress'): for each variable, count rows where
  n=='<11' and stat in {LEVEL,OTHER,MISSING}. If count==1: find candidates (stat in
  {LEVEL,OTHER,MISSING}, n not '<11', n numeric > 0). Suppress all candidates tied at
  min(numeric n). If count!=1: no complementary action.

Summary text rules:
  LOW_CARD (not all_missing): top-3 LEVEL rows by sort_order ascending.
    Format: "Val1 X.X%, Val2 X.X%, Val3 X.X%"
    If n for a row is '<11': show '<11' not pct.
    Truncate level at 20 chars with '…' if longer.
  HIGH_CARD: "N distinct: {n_distinct_val}; top: Val1 X.X%, Val2 X.X%"
    n_distinct_val from N_DISTINCT stat row.
  CONT_NUM / DATE: "mean {MEAN} (SD {SD}); median {MEDIAN} [{Q1}–{Q3}]; min {MIN} – max {MAX}"
    Apply age topcode display for age vars (values already replaced in df).
  NUM_TEXT: "mean {MEAN} (SD {SD}); median {MEDIAN}; {N_UNPARSED} unparsed"

  SUPPRESSED: "Values withheld; length {MIN}–{MAX}" if display_format=='LENGTH'
              "Values withheld; range {MIN}–{MAX}" otherwise.
    MIN/MAX from RANGE_MIN/RANGE_MAX stat rows (value column) if present, else MIN/MAX stat rows.
