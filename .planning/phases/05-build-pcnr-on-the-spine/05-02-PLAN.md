        Rows MUST document:
          - Each sheet purpose (GAPFILL, SPINE_COVERAGE, CONFLICT_SUMMARY, CONFLICT_DETAIL, TYPECHECK)

          - Provenance scope (item 14): spine-origin cells are NOT listed in pdd.qc_pcnr_provenance;
            only gap-filled cells for 2+-source variables appear there
          - conflict_type values: SPINE_VS_SOURCE and SOURCE_VS_SOURCE definitions
          - Type resolution: N8 vs C meaning

      assert_input(sheet_name, headers, rows) -- validate:
        (a) All required columns for sheet_name are present in headers; raise ValueError listing
            any missing column names (item 18).
        (b) If sheet_name == "CONFLICT_DETAIL" and len(rows) > CONFLICT_DETAIL_CAP:
            raise ValueError(f"CONFLICT_DETAIL has {len(rows)} rows, max {CONFLICT_DETAIL_CAP}") (item 18).

      write_workbook(sheets, out_path) -- build Workbook, remove default sheet, iterate SHEET_ORDER.
        KEY sheet from _key_rows().
        For each non-KEY sheet in SHEET_ORDER:
          data = sheets.get(sheet_name, ([], []))  -- (headers, rows)
          call assert_input(sheet_name, headers, rows)  -- raises on bad input
          if headers is empty: ws.append(["(no data)"])  -- always write header row
          else: write_table(ws, headers, rows, _int_col_indices(headers))  -- 0-row data OK (item 18)
        style_sheet each. mkdir parents, wb.save.

      verify_workbook(path, expected_data_rows) -- load_workbook read_only; assert
        sheetnames == SHEET_ORDER; for CONFLICT_DETAIL assert max_row-1 <= CONFLICT_DETAIL_CAP.
        Raise ValueError on mismatch.
