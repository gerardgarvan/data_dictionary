<interfaces>
Test harness pattern: the test file %includes 05_build_pcnr_macros.sas (which defines all
macros). The macros accept parameters (srclib=, name_map=, name_map_vars=, priority=,
override=) rather than hard-coding pdd.* and docs/* paths, allowing WORK datasets to be
substituted. Where macros do not yet have dataset-parameter overrides, the test file builds
WORK datasets under the names the macros expect (work._nmv, work._priority, work._override,
work._type_resolution, work._pcnr_accum, etc.) directly, then calls the macro.

Synthetic data constraints:
  - Small spine: 10 rows, norm_psid values 'P001'..'P010' ($64), no blanks, no duplicates.
  - 3 PCNR_ variables: PCNR_AGE (N8), PCNR_NAME (C20), PCNR_CODE (type_conflict='Y', 1 char
    source + 1 numeric source).
  - 2 non-spine sources: S01 (has values for PCNR_AGE and PCNR_NAME), S02 (has PCNR_CODE).
  - Override: pin PCNR_NAME to S01.
  - Priority: S01 rank=1, S02 rank=2, S09 rank=9 note=spine.
  - All work.* datasets mimic the schemas documented in 05-CONTEXT.md and the plan interfaces.

Test result macro pattern (all inside %macro/%mend, C3 safe):
  %macro _assert(case=, condition=);
    %if &condition %then %put TESTRESULT: &case PASS;
    %else %do;
      %put TESTRESULT: &case FAIL;
      %let _n_fail = %eval(&_n_fail + 1);
    %end;
  %mend;
  %let _n_pass = 0; %let _n_fail = 0;  /* in open code: only %let, no %if */
  After all tests: %put SUMMARY: &_n_pass passed, &_n_fail failed;

PCM rules: no open-code %if/%do (C3); no CALL EXECUTE (item 9); no ANSI SQL (C2); all macros
defined before called (C13 -- %include at top loads all).
</interfaces>
