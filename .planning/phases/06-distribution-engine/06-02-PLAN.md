<decisions>
D-02 two percents: pct_total = n/&_p6_total*100 (all rows sum 100); pct_nonmiss = n/n_nonmiss*100,
  blank (.) on MISSING row and on N_DISTINCT row. Use PROC FREQ MISSING option so the missing
  row is produced, then recompute pct_total manually (override FREQ PERCENT).
D-03 HIGH_CARD order: sort_order 0=N_DISTINCT (stat='N_DISTINCT', n=distinct non-missing count,
  both pct blank); 1..10 top-10 freq desc; 11=OTHER (stat='OTHER', n=sum remaining non-missing);
  99=MISSING (stat='MISSING', pct_nonmiss=.).
D-04 small_cell_flag $1: 'Y' if n<11 else 'N' on every level/OTHER/MISSING row; blank on N_DISTINCT.
D-06 DATE: same nine stats as CONT_NUM; display_format = format name on those rows.
D-07 100% missing: single MISSING row n=&_p6_total, pct_total=100, pct_nonmiss=., sort_order=99.
D-08: after assembling a variable's rows assert sum(n where stat ne 'N_DISTINCT')=&_p6_total;
  %fail_out on failure.
</decisions>

No CALL EXECUTE — DATA _NULL_ FILE= + %include only.
