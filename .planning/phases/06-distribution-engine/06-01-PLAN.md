    %p6_classify_vars(lib=, ds=, prefix=): builds work._p6_vars with one row per profiled variable.
    Steps:
    1. Build exclusion list (D-05):
       - Always exclude NORM_PSID.
       - If pdd.name_map exists (%sysfunc(exist(&lib..name_map))): PROC SQL select the PCNR_ names
         where status='LINKAGE_ONLY' into a macro var list; exclude those too.
       - Else: %put NOTE: [06_profile] name_map unavailable -- excluding NORM_PSID only.
       Use upcase() comparisons so case does not matter.
    2. PROC SQL create work._p6_meta from dictionary.columns where libname=upcase("&lib") and
       memname=upcase("&ds") and upcase(name) ne 'NORM_PSID' and name not in (excluded list);
       keep name, type, length, format; order by name.
    3. Per-variable distinct non-missing count: generate one DATA _NULL_ FILE= include that writes,
       for each variable, a PROC SQL "select count(distinct &var) ... where &var is not null" into a
       macro var; OR (recommended, RESEARCH Q7) load names via call symputx and loop
       %do _i=1 %to &_p6_nv with "select count(distinct &&_p6v_&_i) into :_p6_nd_&_i". Store n_distinct.
       Write the generated file to "&logs_path.\06_classify.sas" and %include it.
    4. Assign var_class into work._p6_vars with these rules, DATE FIRST (D-06 precedence):
       - DATE if type='num' AND ( upcase(format) begins with any of:
         DATE DATETIME TIME YYMMDD MMDDYY DDMMYY JULIAN MONYY WORDDATX WEEKDATE )
         OR ( format is blank AND ( upcase(name) ends '_DATE' OR upcase(name) ends '_DTTM' ) ).
         DATE applies even when n_distinct <= 20 (D-06: dates keep DATE tier).
         Set display_format = the format name (strip).
       - else LOW_CARD if n_distinct <= 20 (covers 0 non-missing, i.e. 100%-missing vars — D-07).
       - else CONT_NUM if type='num' (n_distinct > 20).
       - else HIGH_CARD (type='char', n_distinct > 20).
       display_format blank for all non-DATE rows.
    5. %global _p6_nv; set to count of work._p6_vars rows.
    Use format-prefix matching via a %do loop over the ten tokens or a regex-free
    index() per token inside a DATA step — not open-code %if (C3). No bare data;/set; (C14).
  </action>
