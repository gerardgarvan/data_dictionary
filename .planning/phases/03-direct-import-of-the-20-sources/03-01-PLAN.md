<objective>
Generate the import specification that drives Phase 3 runtime import.

Produce `sas/03a_build_spec.sas`: a standalone, one-time program that (1) does a raw $32767
character pre-pass over the 16 CSV files to find true max observed lengths, (2) probes numeric
columns for the correct informat (best32. then datetime variants; force C if nothing parses 100%),
(3) builds the import_spec from `pdd.header_inventory` + type-override rules, (4) writes
`docs\import_spec_generated.csv` (no PHI), committed to git.  Gerard edits
`docs\import_spec_overrides.csv` (same columns, only changed rows) to override; 03_import.sas
merges at runtime.  s17_ambig_enc.csv is NOT written here -- the 6 ambiguous tokens are derived
at runtime in 03_import.sas.

Purpose: Separate the expensive one-time metadata derivation from the repeatable import.
Output: sas/03a_build_spec.sas, docs\import_spec_generated.csv, pdd.raw_char_lengths.
</objective>

    SAS_TYPE FORCE-CHAR RULES (apply in this priority order; first match wins):
    1. `upcase(strip(orig_col_name)) =: 'ENCRYPTED_'`  (starts with ENCRYPTED_) → force C
    2. `prxmatch('/(_ID|_CODE)$/i', strip(orig_col_name))` → force C
    3. `prxmatch('/^(CPT|ICD)/i', strip(orig_col_name))` → force C
    4. `upcase(compress(orig_col_name,' _')) = 'PRECEDESTUDYID'` → force C
    5. `upcase(strip(orig_col_name)) in ('BASE PROCEDURE CODE 1','PRECEDE STUDY ID')` → force C
    Otherwise: 'C' if inferred_type='char', 'N' if inferred_type='num'.

    NUMERIC INFORMAT PROBING (applies only to rows where initial sas_type='N' after force-char rules):

      parse_fail_best32 + (input(v, ?? best32.) = . and v not in ('','NULL','.'));
    If parse_fail_best32 = 0 for the column: assign informat='best32.' (and format='').
    If parse_fail_best32 > 0: try in order: anydtdtm21., anydtdte10., e8601dt26., e8601da10., mmddyy10.
      For each candidate informat, count values where input(v, ?? <informat>) = . and v not in ('','NULL','.');
      assign the FIRST informat whose parse_fail count = 0; set format to the matching display format
      (DATETIME21. for anydtdtm/e8601dt; DATE9. for anydtdte/e8601da/mmddyy).
    If NO informat parses 100%: force sas_type='C'; record in notes: 'forced to char -- no numeric informat parsed 100%'.
    Record parse_fail_best32 in notes for all N columns: 'numeric parse_fail_best32=N'.
    For XLSX N columns: trust the engine; assign informat='best32.' and format='' (no probe needed).
