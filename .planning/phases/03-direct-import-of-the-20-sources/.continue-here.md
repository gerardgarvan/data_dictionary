<context>
Root cause of 03 failure: `_write_csv_step` macro had %if/%do blocks inside a `data _null_; file ...; put "...";` context. SAS tokenizes the DATA step before macro expansion in some contexts, causing macro keywords to be seen as quoted string content -> "Expected close parenthesis after macro function invocation not found", "Macro keyword LET appears as text", "A dummy macro will be compiled". Only 2 header lines were written to the generated file. Fixed by replacing with a pure DATA step that reads work.spec and uses DATA-step if/then/else with array buffers.

Linter currently shows 0 errors after the first C3 fix, 2 remaining. sas_lint.py already has C1-C10, W1-W2. Need C11/C14 (C13 as W3).
</context>
